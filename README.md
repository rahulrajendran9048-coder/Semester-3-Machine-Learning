# 📊 Data Preprocessing Lab -- Experiment 1

This repository contains **Experiment 1: Data Preprocessing Using
Jupyter Notebook**, completed as part of the **Machine Learning Lab**.

## 📌 Objective

To perform data preprocessing on the Google Play Store dataset using
Python and Jupyter Notebook.

## 🛠️ Tasks Performed

-   Load and inspect the dataset
-   Handle missing values
-   Remove duplicate records
-   Detect and treat outliers
-   Encode categorical variables
-   Apply feature scaling
-   Generate a correlation matrix and heatmap
-   Perform feature engineering
-   Split the dataset into training and testing sets
-   Save the cleaned dataset

## 💻 Technologies Used

-   Python
-   Jupyter Notebook
-   Pandas
-   NumPy
-   Matplotlib
-   Seaborn
-   Scikit-learn
